# Photos

This is the one shared photo folder for the whole store.

Upload the product photos here (in GitHub, open this folder and use Add file → Upload files).

When you are done uploading, tell Muse — and I will update every page to use the photos from this folder instead of the old ones.

Tips:
- Use JPG for photos, high quality.
- Keep the file names simple — the name you give the file is the name the pages will use.
